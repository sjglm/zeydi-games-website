# ZeYDi Games

A responsive game studio website featuring Ossuary, Black Tide: Forsaken, Drone Defence, So You Think You Can Talk? and King's Table.

Built with HTML, CSS and JavaScript. No dependencies or build step are required. Google Fonts are optional, with system font fallbacks for offline viewing.

## Preview locally

Open `index.html` directly, or run:

```sh
python -m http.server 8765
```

Then open `http://localhost:8765`.

## GitHub Pages

In the repository's **Settings > Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. The `.nojekyll` file enables plain static-file hosting.

## Content and artwork

Game descriptions are in `index.html` and panel styling is in `styles.css`.

So You Think You Can Talk? uses `assets/sytyct/library-hero.png`, with text and a Steam link overlaid on the artwork. The other games currently use abstract CSS backgrounds that can be replaced with game artwork.

Drone Defence is a VR game. King's Table features described as planned are still in development.

All game artwork and branding remain the property of their respective owners.
